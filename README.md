# Showcase & Gallery Website

Progetto completo Single Page Application (SPA) per la presentazione di schede descrittive e galleria di immagini.

## Struttura
- `backend/`: Server Node.js + Express + TypeScript con API REST.
- `frontend/`: App SPA reattiva con Vite + TypeScript, CSS moderno (Dark Mode) e Lightbox Modal.

## Istruzioni di Avvio

### 1. Backend API
```bash
cd backend
npm install
npm run dev
```
Il server sarà attivo su: `http://localhost:3000`

### 2. Frontend
```bash
cd frontend
npm install
npm run dev
```
L'applicazione web sarà accessibile su: `http://localhost:5173`
